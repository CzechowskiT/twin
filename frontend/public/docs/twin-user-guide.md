# TWIN user guide

TWIN is your autonomous career agent: it surfaces **matched roles**, tracks **applications**, and helps you land **interview slots worth showing up for** — not inbox noise.

## Quick start

1. **Register** and accept required consents.
2. Complete **onboarding** at `/onboarding` (profile, calendar, pipeline).
3. Open **Dashboard** — review matches, save roles, and apply when ready.
4. Connect **Google or Microsoft calendar** so interview holds sync to your real calendar.
5. Use **WebCal subscribe** if you prefer Apple Calendar or any ICS client.

## Dashboard

- **Matches** — AI-scored roles aligned with your profile.
- **Applications** — pipeline status and recruiter feedback insights.
- **Calendar strip** — upcoming interviews and export/subscribe links.

## Placement verification

When you accept an offer, use in-product placement verification (work email confirmation). See product copy on the applications panel.

## Privacy

You control marketing and product-update emails in profile settings. Core service emails (password reset, placement verification) are transactional.

## Support

Use the **?** help widget in the app or send feedback from the dashboard tutorial.
