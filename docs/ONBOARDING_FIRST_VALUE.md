# Onboarding — pierwsza wartość w < 10 minut

Cel: nowy użytkownik (beta / inwestor na koncie demo) **widzi sens produktu** zanim znudzi się formularzem.

## Kolejność (dla Ciebie jako hosta lub checklisty w produkcie)

1. **Konto** — rejestracja lub login; hasło w menedżerze.
2. **Zgody** — wszystkie wymagane (w tym AI / dane o ofertach — **auto-apply zwróci 403 bez nich**).
3. **Profil** — imię + 1–2 pola, żeby ranking miał sens.
4. **CV** — jeden plik; bez treści CV auto-apply i dopasowanie wyglądają słabo.
5. **Panel → oferty** — włącz filtr jeśli trzeba; **zapisz jedną aplikację** (`pending` wystarczy) albo oznacz „applied”, jeśli pokazujesz pipeline.
6. **Opcjonalnie** — jedna oferta Pracuj + auto-apply **po** udanym teście na stagingu (HTTP może trwać długo).

## Materiał marketingowy

- **Loom / krótkie wideo** (2–3 min) z tej samej ścieżki — do maila, Twittera, decku; nie tylko backup na złe Wi‑Fi.
- Skrypt mówiony: problem (chaos kart) → jeden feed + pipeline → dowód (metryka z `/public/mvp-stats`).
