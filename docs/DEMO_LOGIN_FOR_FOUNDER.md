# Logowanie do demo TWIN (dla founderów)

Krótka instrukcja bez terminala — do pokazania inwestorom lub do własnego testu na produkcji.

## Adres aplikacji

Otwórz w przeglądarce: **https://twin-sooty.vercel.app**

(Zaloguj się przez ekran logowania / rejestracji — użyj danych demo poniżej.)

## Konto demo

| Pole | Wartość |
|------|---------|
| **E-mail** | `demo@twin.career` |
| **Hasło** | Skontaktuj się z zespołem dev po hasło (bezpieczny kanał: wiadomość od agenta, 1Password, Signal itp.) |

Hasło **nie jest** zapisywane w repozytorium. Przy każdym resecie demo generowane jest nowe — zespół dev może je ustawić ponownie bez Twojej ingerencji.

## Co powinieneś zobaczyć po zalogowaniu

- Profil kandydata z danymi demo (oferty, aplikacja, rozmowa w kalendarzu — zgodnie z seedem inwestorskim).
- Publiczna strona demo (marketing): https://twin-sooty.vercel.app/demo

## Gdy coś nie działa

- Sprawdź, czy wpisujesz e-mail **dokładnie** `demo@twin.career` (małe litery).
- Jeśli hasło nie przechodzi — poproś zespół dev o **reset konta demo** (to normalna operacja, bez Twojego udziału w terminalu).
- Status API (dla dev): https://twin-production-bcd9.up.railway.app/api/v1/health

## Bezpieczeństwo

To konto służy **tylko** prezentacji produktu. Nie używaj tego hasła nigdzie indziej i nie udostępniaj go publicznie.
