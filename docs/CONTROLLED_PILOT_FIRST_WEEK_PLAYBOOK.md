# Controlled pilot — first week playbook + exit/expansion

## Preconditions

- Pilot READY · Launch NO-GO · Enrollment OFF  
- FOUNDER_APPROVED real org + SENT invitation pack  
- On-call primary/secondary CONFIGURED  
- Canonical URL: `https://twin-sooty.vercel.app`

## Day 0 (send day)

1. Confirm pack SENT + outbox drafts.  
2. Status CLI: `python scripts/controlled-pilot-os-status.py`  
3. Open support ticket channel (`contact@twin.care`).  
4. Do **not** flip Launch / Enrollment / Phase 3B.

## Days 1–7

| Day | Focus |
|-----|--------|
| 1 | Recipients can login; consent complete; profile started |
| 2 | First match / inbox visibility |
| 3 | Calendar connect (Google or ICS fallback) |
| 4 | Feedback form / support ticket triage |
| 5 | Defect triage board (P0/P1 only) |
| 6 | Weekly review notes (KPI still honest) |
| 7 | Go / no-go for expansion **within pilot** (still not public Launch)

## Exit criteria (pilot org)

- Org completes week without P0 open  
- Named feedback captured  
- No GDPR incident  

## Expansion (still controlled)

Add second FOUNDER_APPROVED org only after week-1 review.  
Public Launch requires `LAUNCH_GO_EVIDENCE_GATE` evidence-ready **plus** Founder Launch decision — separate from expansion.

## Launch communications plan (draft only)

- No press until Launch GO

- Internal: on-call + support queue  
- Marketing site: no fake logos; twin.care not claimed live until DNS
