# Internationalization (i18n)

## Rule

**No user-facing copy as string literals in UI components or API responses** unless it is locale-aware.

- **Frontend:** all visible text goes through `t()` in `frontend/src/lib/i18n.ts`. **EN** and **PL** are fully inline; **es–ja** merge base overlays, **marketing home** overlays (`frontend/src/lib/overlays/marketing-home.ts` + `marketing-home-below-fold.ts` for stats, live counter, rewards band, FAQ teaser), **FAQ locale** overlays (`frontend/src/lib/overlays/faq/` — full `/faq` + homepage persona cards; regenerate via `npx tsx scripts/seed-faq-locale-overlays.ts`), **global chrome** overlays (`frontend/src/lib/overlays/site-chrome.ts` for footer, momentum rail, marketing nav labels), and premium product overlays (`frontend/src/lib/overlays/premium/`). See `docs/I18N_FULL_TRANSLATION_COVERAGE_2026-06-08.md`, `docs/RENDERED_LOCALE_LEAKAGE_HARDENING_2026-06-09.md`, `docs/HOMEPAGE_BELOW_FOLD_I18N_LEAKAGE_FIX_2026-06-09.md`, `docs/GLOBAL_CHROME_ZERO_ENGLISH_LEAKAGE_FIX_2026-06-11.md`, and `docs/FULL_I18N_ZERO_MIXED_LANGUAGE_FIX_2026-06-11.md`.
- **Backend:** AI fallbacks, PDF labels, and user-visible errors must use `locale` from the request (`X-Locale` header, then `Accept-Language`). See `app/services/request_locale.py`.

## Frontend → API

`LanguageProvider` sets the active locale on every `apiFetch` / `apiFetchBlob` via the **`X-Locale`** header (`frontend/src/lib/api-locale.ts`, `frontend/src/lib/api.ts`). The Next.js `/api/v1` proxy forwards client headers to FastAPI.

Optional per-call override: `apiFetch(path, { locale: "pl", ... }, token)`.

## Backend services

Pass `locale=locale_from_request(request)` into:

- CV tailoring (`build_cv_tailoring_blob`, `build_motivation_text_for_auto_apply`)
- Auto-apply orchestration and package PDFs
- Career assistant ATS CV optimization (tailoring step)

Default when no header: **`en`**.

## Regenerating stored content

Saved `cv_tailoring` in `profile_signals_json` keeps the locale it was generated with. After switching UI language, use **Generate & save** again on the profile CV tailor panel so pitch text matches the active locale.
